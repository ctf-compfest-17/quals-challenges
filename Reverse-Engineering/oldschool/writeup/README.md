# Oldschool writeup

[Reference](https://youtu.be/aF1Yw_wu2cM?si=8tmBGfX8JWnrmK2q)

Soal ini more or less nge implement compression algorithm yang dipake Gen 1 Pokemon games, cuma dengan versi lebih "modern", as in dibanding nge compress 2 bpp images, ini nge compress 24 bpp images. Raw 24 bpp imagenya basically pake BMP bagian pixel array datanya dan dari 3 color plane (RGB) di pecah jadi plane masing-masing yang nanti bakal di encode baru di compress. Encoding modenya ada 3 dimana disini basically di berdasarkan current time tapi di tulis flag mode yg dipakenya di compressed filenya (2 bit), jadi bisa tinggal diliat yg mana yg kepake. Compression yang dilakukan tergantung dari pair of bits yg lg di proses skrng, kalo pair of bits nya bernilai `00`, dia bakal pake Run Length Encoding trus di compressed filenya simpen 2 nilai, LV (sama persis kyk video cuma skrng individually 32 bit karena 8 dan 16 kekecilan). Kalo pair of bitsnya selain `00`, dia basically bakal copas doang pair of bitsnya ke compressed file dan kalo ketemu pair `00` lg datanya bakal di terminate pake `00` dan balik lg ke proses pair `00`. Nah buat bedain yg skrng mau di proses itu hasil RLE atau bukan, ada di bit paling pertama, kalo 0 berarti RLE, kalo 1 berarti data. Tiap plane bakal di compress begitu tapi gak ada pemisah secara eksplisit, pisahinnya harus dari kalkulasi apakah jumlah bit yg udh dibaca sesuai dengan besar plane. Besar planenya itu basically `width * height`, dimana di compressed filenya 14 bit pertama adalah width dan height dalam `tiles`, kalkulasi `tiles` udh dilakuin di kode, 1 tile basically terdiri dari 8 pixel, jadi buat dapetin balik width dan height dalam pixel tinggal ambil 7 bit pertama trus kali 8. Dari situ bakal didapet width sama heightnya 1000 pixel, dan karena dari kode di enforce harus 24 bpp di BMPnya, yg berarti 3 bytes/pixel or total 3\*1000\*1000 bytes untuk the whole image, or 1\*1000\*1000 bytes untuk 1 plane. Kalo dari jumlah bit yang dibaca (dan di expand buat pair `00` yg di RLE) udah sampe 1\*1000\*1000, berarti next bit yg dibaca adalah initial packet untuk plane selanjutnya. Begitu terus sampe plane ke 3 (biru).
