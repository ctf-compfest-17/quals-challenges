## Deployment
- Install docker engine>=19.03.12 and docker-compose>=1.26.2.
- Run the container using:
    ```
    cd src && cd images && ./build.sh && cd .. && cd challenge-eth && docker compose -p phantom-thieves up --build -d
    ```
- Stop the container using:
    ```
    cd src && docker compose -p phantom-thieves down --volumes
    ```
